## Problem Statement

The bare word "pause" is overloaded across the workflow system: sometimes the operator means *interrupt the current turn / course-correct mid-flight* (cheap, reversible, no artifact), other times *invoke the session-pause skill* (expensive — writes `workflow-system/state/.session.md` + a full handoff, wrong when unwanted). A 387-turn / 11-project raw-log audit (`tmp/pause-terminology-audit.md`) confirmed the bite is real AND bidirectional: a confirmed false-positive shows the agent inventing a session-pause off the word *"defer"* (no "pause" utterance present), writing `.session.md`, then having to `rm` it. The operator has self-trained to say "pause **the session**" and to append guard phrases ("DO NOT invoke the session pause skill") — workarounds for missing vocabulary. Separately, `/session-resume` prefix-collides with the built-in harness `/resume`, forcing a down-arrow on every resume.

**Settled vocabulary (operator-aligned 2026-07-21):**
- **Turn-level** (cheap, no skill): bare "pause" / "stop" / "hold" = interrupt only, never writes `.session.md`.
- **Session boundary** (writes `.session.md`): RENAME `session-pause` → **`session-handoff`**, `session-resume` → **`session-restore`**. Dual-register (prompt phrase + skill name). "restore" kills the `/resume` collision; "handoff" matches the operator's own name for the artifact (".session.md is a handoff doc"); `session-` prefix preserved.
- **Cross-project** (WP8/future, name reserved only): `/project-handoff` — the `session-`/`project-` prefix disambiguates the two handoff scopes.
